# FastaGuard v1.0.0-rc.1 — Reference Contract Gate

## Release candidate

FastaGuard v1.0.0-rc.1 prepares the Reference Contract Gate for release. It is
not a public release and does not claim published GitHub, Bioconda, or
BioContainers artifacts.

## Reference compatibility

`fastaguard reference` compares explicitly supplied reference declarations with
one canonical FASTA. It supports FAI files, SAM sequence dictionaries, BAM and
CRAM headers, VCF and BCF contig declarations, and GFF3 sequence declarations.
It does not discover sidecar files implicitly or inspect alignment and variant
records.

The command provides strict, coordinate, and advisory policies; reports stable
findings in JSON, TSV, HTML, and MultiQC-compatible outputs; and can write a
portable lockfile for the reference identity and declared artefacts.

## Compatibility

Existing assembly and compare reports retain schema version `0.7.0` and their
documented fields. They coexist with Reference Contract schema version `1.0.0`.
The nf-core and Snakemake examples remain separate adapters that consume
FastaGuard output without changing their existing workflow interfaces.

## Candidate checks

The release candidate is qualified with deterministic Rust and Python tests,
schema validation, package-archive checks, and local workflow smoke tests. A
public release still requires an authorised tag and publication run.
