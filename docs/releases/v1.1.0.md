# FastaGuard v1.1.0 - Reference Workflow Adoption

Status: released on GitHub. Bioconda and BioContainers remain at v1.0.0.

## Reference workflows

This release adds Nextflow and Snakemake examples for using
`fastaguard reference` before downstream work. Both support a single reference
bundle on a local or shared filesystem, with explicit FASTA and companion-file
dependencies.

- `report` mode saves the reports without enforcing the compatibility decision.
- `enforce` mode checks `gate.can_continue` before a demonstration downstream
  task can run.
- A blocked gate leaves the completed HTML, JSON, TSV and MultiQC reports
  available for inspection. A reference lockfile is optional.
- Input and report checks protect existing evidence during retry or resume;
  changed inputs require a new run identifier.

The [workflow examples](../../examples/reference/README.md) include the
configuration files and synthetic fixtures. They are supplied in the repository
source, not the standalone binary archives. They do not modify input files or
perform a biological downstream analysis. Object-store publication and
multi-bundle orchestration are outside their scope.

## Verification and documentation

The dedicated CI job pins Nextflow 26.04.6 with Java 17 and Snakemake 9.25.2
with Python 3.12. It runs both workflow linters, the eight-case decision matrix,
report retention and retry checks. Required mode fails if an engine is missing
or a fixture filter would reduce the matrix.

The reference quickstart and installation guidance now separate source builds
from published packages. Reference memory use, identity guarantees and
publication limits are documented more precisely. The workflow fixtures test
software behaviour; they are not additional biological validation evidence.

## Compatibility

There are no changes to the CLI's analysis or exit-code contracts. Assembly and
compare reports retain schema version `0.7.0`. Reference reports retain schema
version `1.0.0`. The new workflow examples also work with the published v1.0.0
reference command.

The existing nf-core module and Snakemake wrapper are unchanged. These local
reference examples are not new upstream workflow components.

## Distribution

GitHub release archives and SHA-256 checksums are published for Linux x86_64,
macOS Intel, and macOS Apple Silicon. Bioconda and BioContainers remain at
v1.0.0. The recipe checksum, container tags and upstream wrapper pins remain
tied to that published version until downstream packages are updated.
